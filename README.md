正式入口：**http://127.0.0.1:8016/**。

主要操作按“地图 / 专题分析 / 任务与成果 / 数据”组织，共用一张地图。客户选择专题、确认范围与日期、运行分析，随后查看指标、图层、实际数据来源并下载成果。文字描述需求保留为折叠辅助入口，数据、参数和算法不由前端虚构。

## V18 真实集合算法与样例清理

参考OpenGE公开的数据集合/算子契约和Google Earth Engine的集合归约、线性回归方法，在本机接入四种真实像元算法：时段中位数合成、时段均值合成、逐像元指数线性趋势、Otsu自动阈值与连通分区。前端“更多分析 → 时序与影像处理”提供两个入口，可按问题选择方法、指数、范围、日期、观测次数和数据源，随后后台自行检索实际影像、定标、质量检查、共格网计算、出图和归档。不是直接调用OpenGE/GEE云端算力，也没有配置它们的账户。

集合一次使用S2或Landsat8/9单一来源系列、2–6个独立UTC日期；合成逐像元至少2次有效观测，趋势至少3次，支持不足保持未知。逐景全有效范围与所有日期共同支持范围分开统计，保存有效观测次数、实际日期、时序CSV、GeoTIFF及可核查成果包。Otsu只对明确成功单期指数求阈值和四邻域分区，保留孔、小斑块过滤前后计数及面积，不把它当作水体、作物或法定农田分类。

按精确证据和依赖关系删除当前库26条不真实样例/衍生记录，保留318条真实或无法证明为虚构的记录并逐条核对SHA不变。移除虚拟xt-fixture、五类合成业务图层、教学样本文件/按钮、旧模拟工作流与假应用预览；旧创建/执行/发布/复制入口返回410，不能重新生成。新公开生产入口只接受原生模式，必须有明确选区和日期，不默认套历史样区。真实公开影像、年度分类、已上传参考水系和行政边界保留；独立临时单元测试夹具不进入业务库。

正式入口仍为8016，服务版本0.18.0。清理备份在`output/diagnostics/v18-sample-recovery-20261115`，不进入交付包，私有Key未改变。

## 上传数据直接上图

地图工具栏选择“上传数据”，导入成功后直接显示并定位WGS84 GeoJSON；不需要先运行统计。点、线、面和多面均保留原始属性，可在地图点击查看。“数据 → 我的上传”支持查看已导入图层、属性和来源，再次显示到地图；“图层 → 我的数据与成果”可独立开关、定位。刷新可恢复最近选择的用户数据。

当前入口仅支持GeoJSON FeatureCollection（最多500要素、2MB，坐标为经度/纬度），不接受Excel、Shapefile、GeoTIFF或投影米制坐标直接导入。详见[上传上图验收](docs/QA_UPLOAD_MAP.md)。

## V16 农业分析算法扩展

“专题分析 → 农业分析”提供植被与土壤背景、红边叶绿素线索、裸土光谱线索、植被覆盖度估算、地块分区统计五个入口。FVC须明确选择已有单期原生NDVI和两个端元，不默认假定模型参数；地块统计须选择已有原生栅格和用户Polygon/MultiPolygon图层，可统计指数分布、≥阈值命中面积或年度分类耕作地参考面积。部分覆盖、未知像元和重叠地块并集分别报告，空统计不填0均值。

## V14 选区耕作地标注

## 直接操作

1. 在地图上搜索“武汉”“仙桃”“武昌区”，或输入`114.205,30.505`定位。地点只是导航参考点；分析范围由用户明确框选。
2. 打开“专题分析”，选择任务并填写范围、观测时段及需要的筛选条件。
3. 点击“运行分析”，查看真实任务步骤、状态、结果指标和地图。
4. 在“任务与成果”恢复历史；“复用条件，再次分析”回到原表单，可修改后提交。
5. 从结果下载GeoTIFF/PNG/来源报告；“核查像元”开启后点击分析栅格，可读真实指数/差值或分类码。

主地图搜索已接统一后端，支持地名参考点、合法WGS84坐标、全部已完成成果、专题名称、实际观测日期和用户数据，不依赖成果已经显示。未收录地名/非法坐标/网络错误分别提示。地点索引为GeoNames中国城市参考快照：2123个城镇点（含湖北56个）加湖北省参考点，共2124；不是完整POI、村镇或行政界库。

## 流程与专业边界

参考Google Earth Engine的地图、数据、参数、任务、Inspector和导出职责分工，使用结构化专题表单服务业务用户；计算仍由本项目已接入的真实引擎完成。

- `/api/applications`提供版本化专题和输入声明，`/api/application-runs`在后端校验参数，冻结application_ref，再进入已有真实执行器。不是前端拼一个标题后显示预设结果。
- 同request_id同输入重放同一任务；换输入返回409。同条件且版本/文件齐全可复用已有真实子任务；取消/重试不会改写历史答案，重试保留原专题和条件。
- 土地覆盖专题不继承地图AOI或月度日期。光谱窗口单边≤0.05°、最多1,048,576参考格；目录与中心天气不误套该像素上限。
- S2每期选一景合格观测，只读所需两光谱波段与SCL；实际拍摄日期单独显示，不把请求窗口称月平均。NDVI/NDWI用10m参考，含SWIR指数用20m参考。
- GeoTIFF统计与预览显示分开。新五指数导出额外保留已定标对齐反射率/SCL，可独立复算；六指数共享数据，NDMI/NDBI在同条件下互为负值，不能按数量包装为独立分类能力。
- 源窗口缓存限64MiB原始数组、128条、30分钟TTL；命中不等于重新联网核验，数组字节不是HTTP流量。SCL先读，不足10%提前失败；SCL7保留但计数提示，有效覆盖不是分类精度。
- 地图“导出矢量范围”准确导出GeoJSON范围/要素；完整像元成果从对应结果下载。像元核查读取本地原生TIFF单格，不从底图或PNG估值；域外/无效为null。
