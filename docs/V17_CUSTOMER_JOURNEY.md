# V17 客户操作与信息层级评审

评审目标：保持一张地图和原有接口，从客户的“选择任务—确认范围与日期—查看结论—取走成果”出发整理页面。没有新增分析算法、业务承诺或导航层级。

## 共同结论

交互、地图视觉、业务架构三方交流后，采用六项常用分析与“更多分析”组合。默认展示耕作地标注、植被观察、植被变化、地块分区统计、影像查询和用户图层统计。其余八项已提供专题按业务任务折叠，专业光谱工具单独保留；全部十五个专题仍可到达，十二指数选择未删减。

正常可用卡片不再反复标注“工具已提供”，保留年度参考、影像指标、上传图层、目录查询等必要性质。固定仙桃历史范围和2024/2021年度分类产品仍在可见位置说明，不能误认为省域现状数据或当期识别。

## 表单

- 范围、观测时段、输入图层、产品年度、分析算法和FVC端元作为主要输入。
- 可选数据源、阈值和筛选关系收进“筛选与数据设置”，摘要始终显示当前选项；更改阈值后即时更新摘要，不改变原请求参数。
- NDRE仅适用Sentinel-2红边波段、20米参考格网仍显著显示；Landsat下SAVI等保留实际30米参考格网，不给自动选源假定固定10米。
- FVC两个端元保持必填且无默认假定，分区统计仅使用明确上传的地块面图层，未改为合成示例。

## 完成结果

完成页先显示结论、主指标、实际日期和关键解释，再显示“下载成果”“查看地图”“单项文件”“来源与方法”。分布图、处理记录和完整输入条件可展开查看，完整质量规则、公式、来源版本与指纹保留在原来源详情和下载记录中。

关键限定并未隐藏：光谱指标不能代替产量或灾损认定；FVC端元未经本地校准；分区只统计源范围交集，未覆盖不外推，重叠可能重复；年度分类不是当期调查。缺测、零值和有效覆盖继续由真实结果决定。

业务专家第二轮还发现执行详情未加载时，FVC可能被错误显示为分区统计说明。本轮以答案中冻结的算法/结果类型作回退，避免延迟加载时出现错误说明。没有读取到分区计数时不填造数字。

## 本代理验证

`node --check dist/map-copilot.js`通过。用预览8017只读API和模块渲染检查：十五个专题均可达且无重复、六项默认展示、NDRE不能使用Landsat、NDRE20米/SAVI Landsat30米可见、修改的阈值摘要可见、FVC未假定端元、执行详情延迟时FVC说明正确、结果在条件之前、完整成果下载在分布图之前。

证据：`output/v17-review/customer-journey-readonly-proof.json`。本代理没有写正式数据库或运行浏览器；真实桌面/手机流程与视觉检查由主代理统一完成。

主代理在预览提交NDVI≥0.3的真实分析后，发现主摘要仍复述“XML定标、SCL、共配准”等处理过程。已改为依据实际结果的业务摘要：`所选范围NDVI均值为0.2213，有效数据覆盖100.0%。其中NDVI≥0.3的格网条件面积为35.70公顷。` 无显式阈值时只显示均值/覆盖，不突出后台默认筛选；两期分析明确后减前及共同有效覆盖。

另用只读结果副本核对：真实0均值/0面积保留为0；0有效像元不把缺测解释为0面积；来源追问和完整来源详情仍保留后端原摘要。证据：`output/v17-review/production-summary-proof.json`。未更改计算结果或后端文本。
