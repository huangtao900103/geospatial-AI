# V18 Otsu分区独立复核

审查日期2026-11-14。审查对象`adaptive_segmentation.py`，不改算法。新增`tests/test_adaptive_segmentation_v18.py`六项测试，全部通过，日志`output/v18-collection/otsu-review-check.txt`。

复核结论：128分箱目标函数与独立标量类间方差计算一致，最低并列最优分割边界规则确定；常量、有效数不足时明确拒绝，不伪造阈值。above为≥、below为<，在有效像元上互补。

临时合成7×7格网用于可控几何检验，未安装到业务库：原始19个命中像元分成4个四连通分区；一个16像元带孔环和三个1像元孤立点。最小斑块2时移除三个小点，保留16像元、一个含孔多边形，面积0.16原生投影公顷。输出WGS84 GeoJSON再转回原CRS回烧，与导出原生二值TIFF逐像元一致；孔没有被填平，斜对角点没有并入环。未知/区域外不参与阈值或面积；全部斑块移除后的0面积为真实条件结果，仍与未知NaN分开。

另只读使用既有真实公开原生NDVI `production_e4981e20877640`，先核对来源为public_satellite_pixels/native，再独立统计阈值命中，核对GeoJSON回烧与原生选择掩膜；源文件SHA256前后相同，没有写正式数据库或覆盖源数据。

未发现双峰数值、孔、连通分区、条件面积、真实0/未知处理的P1错误。小P2建议：接口文案要求“北向上”时，除旋转项b/d为0外还检查transform.a>0、transform.e<0；现有公开供应商源实际为正常北向格网，公共来源链不会因此产生当前结果错误。

Otsu只产生光谱自动分区，不能据此把亮/暗两组直接命名成水体、农田、作物或灾损。结果面积为原生格网条件面积，分区不是权属宗地；有效覆盖和直方图分离度不等于独立分类精度。

主集成已落实格网符号约束：transform.a须大于0、transform.e须小于0，旋转项须为0。
