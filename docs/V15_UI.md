# V15 界面与客户流程验收

界面保持专业蓝白工作台与遥感影像一张图。地图顶部“在图上提问”和右侧常驻输入框成为直接需求入口；常用分析保留为固定能力，卡片显式说明历史分类、固定区域、光谱计算、目录、天气模型或用户图层统计。

分类专题可明确选择IO2024或WorldCover2021。新自由标注问题未说明年份时，页面提示采用2024年度参考；有明确年份则尊重原文。旧快捷问法、引用和历史答案不换名。结果同时显示面积、图斑数、有效覆盖、未知区域说明与完整成果包；年度、类别、面积方法和来源可展开核查。

业务接入清单可查看六类场景所需台账和接口。已有基础工具不被描述为部门系统已接通。新问题与待补条件分开，范围口径不明时提供“按当前地图选区分析”续办，并保留原文、bbox、产品和问题引用。

真实浏览器证据为`output/playwright/v15-artist-browser-validation.json`。已核验2024非零73.65公顷、2024真实零值、2021历史22图斑、像元核查class5/2024、包内逐项SHA和GIS回烧、390手机无溢出。正式页面另留`v15-formal-desktop.png`和`v15-formal-mobile.png`，最后控制台0错误。

这些操作验证历史分类产品提取与GIS流程，不证明当地当期农田识别精度。完整结果与数据保留说明见`QA_V15.md`。
