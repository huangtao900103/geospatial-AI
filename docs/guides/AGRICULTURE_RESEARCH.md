# 作物与时序：真实数据、分类研发与变化核查

入口：一张图 → 专题分析 → 农业 → 作物与时序。时序观察、作物样本和变化核查共用当前地图，不增加独立业务页面。

## 本轮实际生产

2026年5—10月检索公开Landsat Collection 2 Level 2目录，统一采用Landsat 8、Tier1、30米投影参考格网和QA规则。每月窗口选一景实际观测，保留目录、场景资产、定标、质量与文件SHA，不称月均或逐日连续监测。

6月1日→8月4日、8月4日→10月7日分别为64天实际观测差值。核查采用所选两日期共同有效像元，不用三日期固定mask替代配对mask。未叠加耕地掩膜，因此属于全市光谱线索；季节、收割、水位与云缺测都需结合资料解释。

## 使用路径

1. 在“时序观察”打开序列，阅读共同范围NDVI；展开水分指数查看同一范围NDMI。逐景自身均值单列，仅作辅助。选择有效日期可上图、点击读原生像元和下载。
2. 在“变化核查”选择真实配对日期，明确变化方向、指数差值阈值及最小像元数，生成四连通候选。缺少共同有效像元返回422，不能把无数据当作零变化。
3. 候选可上图、下载GeoJSON并逐条记录待核查、已核实、已排除及说明。状态与历史追加保存，原始栅格和几何不变。人工状态不自动转作作物训练真值。

显示最多1500个候选，超出数量单列；页面面积仅合计显示候选，不冒称全体面积。默认不填阈值，由使用者按业务说明选择。相同观测对的原始变化和质量比较副本不可重复累计。

输入框也可直接问“查看仙桃市2026年5月至10月长势时序”。登记的`agri_series_read`工具先核验范围、时段、单一传感器及两类内容版本，再返回实际归档，保存完整时序快照。来源／下载追问继承同一快照。地图是最近有效观测的NDVI，NDMI在水分曲线呈现；不会把NDVI图称为NDMI图。不同年度、选区或源不匹配时说明缺口，不替换为2026仙桃数据。本轮真实HTTP链路读取约0.66秒，来源／下载追问约0.44秒，均为本机已归档数据读取耗时，不是影像生产耗时。

## 作物样本与模型的真实边界

当前没有取得适用于仙桃2026目标作物季节的独立已核实样本，因此不发布本地监督训练的水稻、油菜分类面积、精度或全市预测图。GlobalRice20 2024的公开历史水稻类别可经独立的分类产品分析入口使用，其年份、来源和参考口径单独保留，不作本地独立验证真值。公开历史点、其他地区样本、既有分类产品及模型自标注不能直接充作本地独立验证真值。

后台已实现真实样本GeoJSON Point登记、原生影像NDVI/NDMI特征提取、空间分组与地块隔离的训练/验证检查、纯NumPy正则化LDA研究基线、模型指纹与预测。客户端传来的特征不作为实际影像值。有质量比较子集时，训练特征仅取合格实际日期，并记录排除日期；全云日期保留在观察序列，不作为整列缺值输入，也不插补。样本来源、许可和核实人员为提供方声明，不等于平台鉴真。

默认每类至少20个训练样本、10个验证样本；训练至少3个空间组、验证至少2组，同一地块或空间块不得跨训练验证；需包含负类other。缺值、重复点和不兼容年度会被排除或阻断。当前5—10月未覆盖油菜完整越冬物候，即使数量达标也不发布三类模型。稻油轮作应按目标季节分别定义标签；全年地块不可强归单一作物。样本留出精度也不等于全市面积置信区间。

## 接口与复算

- `GET /api/agri-research/catalog`
- `GET /api/agri-research/series/{id}?series_sha256=...`
- `GET /api/agri-research/series/{id}/files/{declared-path}?series_sha256=...`
- `POST /api/agri-research/samples`：`{name,series_id,geojson,label_source:{method,reference,license,verified_by}}`，点属性包含`label,crop_year,field_id,split`。
- `POST /api/agri-research/train`：`{sample_set_id}`。
- `POST /api/agri-research/reviews`：`{series_id,change_id,threshold,min_pixels,direction}`。
- `GET /api/agri-research/reviews/{id}`及`/{id}/geojson`。
- `POST /api/agri-research/reviews/{id}/status`：`{candidate_id,status,note}`。

时序版本覆盖结果、所有声明文件和地图发布映射；版本不符409。文件只允许声明路径，不接受任意URL、代码或Shell。观测图、变化图沿用原成果版本固定与原生栅格读取。

`scripts/production/produce_xiantao_series.py --help`列出有界公开数据生产与离线复核；`scripts/production/publish_agri_series.py`发布已独立验证的新版本，禁止覆盖同ID。独立复核重开原生QA/反射率/差值，实际检查13,958,700个市界像元，公式最大误差0。它验证计算一致性，不认证作物分类精度或行政边界权威性。
