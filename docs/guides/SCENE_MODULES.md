# 行业场景与勾选配置

专题分析按农业、林业、水利、交通组织，共22项场景。农业13项包括耕地底数、高标准农田、尾水治理、粮食与重要农产品、防灾减灾、长江禁捕、北斗农机监管、养殖场所、农资门店、冷链加工、确权延包、黄鳝产业链、秋冬播。

每项场景现在可直接选择或上传GeoJSON台账，筛选记录、按状态分组、统计唯一主体、汇总数值字段及单位，计算面几何面积或线路长度，并把结果上图和归档。运行后的数据绑定、字段口径和结果保存在后端，可在刷新、服务重启后恢复。缺失值、非数值和真实零值分别统计。

客户流程：选择场景 → 选择或上传数据 → 按需展开“分组、汇总与筛选” → 运行统计并上图 → 下载成果。农机要求LineString轨迹，工程面积要求面；WGS84、500要素、5000坐标点及请求大小限制仍适用。结果包包含完整输入、筛选后GeoJSON、CSV、方法与来源及SHA256清单。

进入遥感工具时，后台按同一筛选规则生成匹配记录的外包矩形，并注明不是地块掩膜；超限或退化范围需要框选子区，日期由表单明确确认。船舶视频、北斗实时定位、权属与交易系统尚需授权接口；不把台账统计和遥感参考冒称执法、工程验收或作业面积认定。

“配置场景功能”可逐项勾选，自动保存在当前浏览器，不跨设备或账户同步；恢复全部场景可重置。零勾选显示配置提示，功能隐藏不删除数据。通用工具提供已登记分析专题，当前清单以`GET /api/applications`为准。专题返回保持原行业和场景上下文。

非聊天页折叠提问区，可选统计设置折叠，结果优先显示；分组颜色与图例一致，时间按北京时间显示。完整验证见[本轮验收](../archive/QA_SCENE_WORKFLOWS.md)。
