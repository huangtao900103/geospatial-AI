# 仙桃农业应用：规则、数据与真实生产路径

案例核查日期：2026-11-15。以下影像窗口、地区事实和成果描述对应该次案例，不是平台的全局日期或地区限制。本文区分可用公开资料实际生产的参考成果、需要授权台账的业务应用及目前不能自动认定的结论。不把历史年度产品标成当前实况，不用机构地址冒充项目位置。

## 一、统一范围和数据口径

当前仓库的仙桃边界来自geoBoundaries gbOpen，代表2017年、72顶点概化Polygon，WGS84；其bbox为[112.921612131,30.093880321,113.831989390,30.536771949]。元数据记录的等面积投影面积约2511.38平方千米，与官方统计参考2538平方千米不同。它适合作公开参考范围，不是当前权威行政界、地籍或工程边界，不应强制缩放面积来吻合统计数。

每份生产成果必须保存：范围文件及哈希、产品/算法版本、真实影像ID与日期、定标、质量掩膜、格网/坐标系、面积方法、云与缺测、统计母体、参数及来源许可。全市参考范围应使用Polygon掩膜，不能把bbox矩形当作全市；若只做选区，必须直接标明选区，不替换全市需求。

### 当前可直接获取的IO2024全市数据

已通过现有固定适配器真实查询官方STAC。49R-2024 supercell完整覆盖参考仙桃市界，公开COG为：

`https://io-10m-annual-lulc.s3.us-west-2.amazonaws.com/49R_2024.tif`

该条目的bbox为[107.7695897396,23.9706984380,114.2304102604,31.9942481574]。50R-2024仅与东缘相交，本次不必跨UTM拼接。应读取49R的必要window并以市界Polygon逐像元掩膜；类别面积、未知区域、像元数及分类GeoTIFF必须同源一致。

官方资料说明该系列覆盖2017至2024年，年度图由全年多次分类预测构成，CC BY4.0，可从公开S3或STAC获取，无需AWS账号。当前本机适配器固定使用2024，不应因“最新”措辞改称2026实况。[数据来源](https://registry.opendata.aws/io-lulc/)

### 时相和质量门槛

- 截止日期不得晚于2026-11-14；日期窗口是检索条件，结果必须另显示实际观测日期。
- 优先同一来源系列、固定定标和QA；不因目录整景云量较低就断言研究区无云。需按AOI实际质量像元计算有效率。
- 单景失败可明确报告失败或部分覆盖；不得用其他年度、单个样点、底图截图或随机数组替代完整区域统计。
- 集合合成每像元至少2个独立有效日期；线性趋势至少3个；支持不足保持未知。比较日期序列时，以共同有效像元为主，自身有效范围均值仅作辅助。
- 若把2024作物类别当作2026观察的参考掩膜，应标明“2024类别参考范围内的2026光谱”，不能保证当前仍为农田或同一作物。
- NDVI差值0.1、MNDWI阈值0等只能作为可调整的筛查参数，须保留参数并提示需本地验证，不直接作播种、灾害或养殖分类阈值。

## 三、高标准农田：公开公告可做真实台账，工程范围不能虚构

已核验湖北省电子招投标交易平台公告：仙桃市2026年高标准农田建设项目（EPC），编号HBXT-202603GT-002001001，发布于2026-03-30。公告计划建设12万亩，其中新建3万亩、改造提升9万亩；项目业主为仙桃市农田开发整治中心。

可以生产真实的公开项目卡、计划规模与来源索引。计划不等于已开工、已完成或验收通过，公告也没有提供可用地块面，因此geometry和实际完成进度应保持空缺；不能把业主办公地址画成项目建设地块。

[官方公告](https://www.hbbidcloud.cn/hubei/jyxx/004002/004002005/20260330/77f8f89e-3bf2-4165-9769-4513ee2c0148.html)

获得授权项目边界、编号和建设/验收时间后，路径为：项目/地块去重 → 工程范围上图 → 实际影像时相选择 → 影像变化线索 → 台账与现场记录核对 → 核查记录归档。10米Sentinel不能直接验收窄田间道路、排水沟或泵站等细设施，需高分影像/无人机及工程资料。

## 四、需要授权数据的业务闭环

| 场景 | 至少需要的真实字段/接口 | 可执行规则与成果 | 不能伪造的结论 |
| --- | --- | --- | --- |
| 长江禁捕 | 有效监管水域面、船舶/巡查记录、事件时间位置、视频/雷达或无人机授权接口 | 空间入区/越界线索、巡查覆盖、事件台账和处置状态 | 公开水体类别不能识别非法捕捞，线索由主管部门核实 |
| 北斗农机 | 设备ID、时间戳、轨迹、作业类型、机具幅宽、定位质量及作业地块 | 先去异常/重复记录，按设备和时间切分轨迹，再关联地块；已有LineString可统计轨迹长度与设备数 | 长度不等于作业面积；幅宽和去重规则不足时不得推算面积或补贴合规 |
| 养殖场所/尾水 | 主体ID、许可、边界/点位、养殖类型、排口和水质实测、设施运行记录 | 主体分布、许可/巡检台账、尾水工程定位与监测关联 | MNDWI不能反演氨氮、溶解氧、达标情况，不能识别黄鳝物种 |
| 农资门店 | 统一主体ID、坐标、许可/经营品类、检查时间 | 门店去重、分布、许可与巡检分组统计 | 地图POI不等于有效许可证或实际库存 |
| 冷链/加工/黄鳝产业链 | 主体ID、节点位置、统计时点、容量单位、加工/物流/交易及检测授权接口 | 同时点同单位汇总、主体关联、流向和质量追溯 | 不从遥感推算容量/交易额，不把二维码认定为单尾真实产地证明 |
| 二轮延包/确权 | 授权权属面、脱敏合同/权属标识、有效期、延包状态 | 权属面与业务状态展示、去重及进度统计 | 年度Crops像元不是确权宗地，几何近似面积不代替权属调查 |

农业农村部的公开禁捕部署说明其真实监管采用船艇、视频、小目标雷达和无人机等手段，并协同市场检查；据此不能把一张水体遥感图冒称已完成禁捕执法。[官方发布](https://cjjjd.ndrc.gov.cn/gongzuodongtai/bumendongtai/202501/t20250102_1395413.htm)

## 五、来源及专业说明

- [ESA WorldCover官方数据说明](https://esa-worldcover.org/en/data-access)：2021 v200是历史年度地图，2020与2021算法版本不同；使用须保留署名。
- [IO / Microsoft / Esri公开数据登记](https://registry.opendata.aws/io-lulc/)：原生10米年度类别、2017—2024、公开COG及STAC。
- [USGS NDVI](https://www.usgs.gov/landsat-missions/landsat-normalized-difference-vegetation-index)：植被绿度与密度变化参考；不是作物类别或产量模型。
- [USGS NDMI](https://www.usgs.gov/landsat-missions/normalized-difference-moisture-index)：NIR/SWIR比值的植被水分线索；不是土壤含水率实测。
- [Sentinel-2 L2A官方数据目录说明](https://developers.google.com/earth-engine/datasets/catalog/COPERNICUS_S2_SR_HARMONIZED)：多分辨率反射率、质量类别及处理基线差异。目录资料用于理解传感器，不代表本平台已经连接Earth Engine云算力；本机仍需遵循实际提供方资产定标。
- [湖北省农业农村厅2026年秋播报道](https://nyt.hubei.gov.cn/bmdt/yw/mtksn/202610/t20261022_6037991.shtml)：江汉平原稻油轮作与腾茬、适墒、播种质量的业务背景。它不是仙桃逐地块作物季历，因此本轮时间窗口仍属遥感观察设计，不是当地已核定播期或种植面积。

公开成果应显示“年度参考”“实际观测”“待业务核查”相应状态；完整区域未生产完时显示真实进度/覆盖，不展示预填完成数值。

## 七、可重复执行的生产入口

生产器不再绑定特定影像ID。输入前后期日期、整景云率上限、候选上限和市界QA门槛后，固定调用Planetary Computer官方`landsat-c2-l2`目录，以当前参考市界bbox检索；候选再按实际足迹是否包含完整市界、日期、云率、所需波段与逐资产定标参数筛选。前后期分别读取市界内真实QA，采用“本轮有界候选中最近且达到门槛”的观测；均未达到时采用最高有效率并明确警示。整景云率不是市界有效率。

每窗最多62天，结束日最多为UTC昨天；每窗QA候选1—4个、目录上限120条，不跟随返回的任意`next`链接。若分页未遍历或候选受限，来源记录明确标注，不宣称遍历全部观测。原生格网继续受700万像元上限控制；一次QA资产读取上限为候选数的4倍，选中场景另读取6个反射率资产（远程失败单资产最多重试2次）。

正式生产示例（默认输出在`output/xiantao/spectral-runs/`新运行目录；不会覆盖已存在的ready成果）：

```sh
.venv/bin/python scripts/production/produce_xiantao_spectral.py \
  --before 2026-09-01 2026-09-30 --after 2026-10-01 2026-11-14 \
  --cloud-max 80 --max-candidates 3 --minimum-qa 0.7
```

追加`--discover-only`只检索并冻结目录，不读取遥感像元；它打印冻结目录位置。随后以`--mode frozen --catalog-dir <冻结目录> --output <新的结果目录>`复用快照生产，不重新检索目录。旧`landsat-YYYY-MM-DD.json`真实目录也可作为冻结输入。冻结新快照另保留`production-request.json`、`catalog-before.json`、`catalog-after.json`、`catalog-manifest.json`和实际QA选择记录；支持SHA校验，不归档临时签名令牌。

`.venv/bin/python scripts/production/produce_xiantao_spectral.py --validate-only`为完全只读复算，不重写结果或验证时间戳。可用`--validation-report output/xiantao/read-only-check.json`将本次报告另外输出到非生产路径。2026-11-15已在临时目录实际验证官方实时检索：前期3条中2条完整覆盖，后期4条中2条完整覆盖；邻轨部分覆盖条目被足迹筛选剔除。本轮接口改造未重跑或改写正式光谱成果。
