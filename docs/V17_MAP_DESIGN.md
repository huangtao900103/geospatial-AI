# V17 地图交互与视觉评审

评审目标：让客户围绕地图找到地方、带入数据、选择范围并理解结果，减少重复入口和技术装饰，不新增业务层级。

## 首轮发现与改进

- 地图顶部的历史仙桃快捷与专题重复，容易让当前选区和历史固定范围混淆。客户模式隐藏这组三个快捷，历史能力仍可从专题访问，专业模式继续保留。
- 主工具按“搜索位置—选择范围—上传—图层”整理。手机采用两行工具条，搜索独占一行，“上传数据”保留文字，不再只呈现一个加号。
- 图层、要素详情改为轻量白色面板，与分析面板统一。保留深蓝工具和卫星影像的对比；减少阴影、圆角、英文大写装饰，使用中文名称和业务标签。
- 用户上传图层的地图图例原先仍提示先运行专题，现改为图层名、要素数和属性点击提示。
- 光谱图例保留变量、原生格网尺度、颜色区间与透明缺测，并加实际观测日期；FVC保留百分比、端元估算说明及实际日期；分区保留完整/部分/域外源数据覆盖解释。手机仅在分析结果已存在且面板收起时展示紧凑图例。
- 配合产品评审，为“更多分析”“可选设置”“完成条件”“关键结果说明”补充原生折叠样式；数据页高级设置和来源连接条件使用轻量折叠菜单。

## 保留的业务边界

搜索地点仅定位地图，不自动声明行政范围已成为分析范围。底图的时相未知提示、分类年度、缺测、端元假设、部分覆盖、面积口径及来源署名均保留。上传、历史成果和原生像元数据未作任何修改，不增加执行算子或虚构业务能力。
