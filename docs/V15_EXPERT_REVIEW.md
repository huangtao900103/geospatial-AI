# V15 联合评审与改进结论

评审日期：2026-11-14。参与角色为系统架构师AI、艺术家与信息设计AI、政府业务视角AI、遥感科学家AI，由主工程代理集成并验收。本记录是产品与工程评审，不代表主管部门审核或法定调查认定。

## 共同判断

项目已能通过问题或专题调用真实数据与算法，保留问题、任务、原生数据统计和GIS成果的对应关系。当前适合作为可验证的本机分析工作台；全省通用的页面不能等同于全省各部门生产系统已接入。

本轮按“独立评审 → 统一产品与执行契约 → 实现 → 交叉找错 → 浏览器和真实HTTP验收”推进。优先改进实际执行和业务解释，再调整视觉层级。没有通过增加虚构业务数据、预设图斑或算法名称来扩大能力清单。

## 已落实的改进

| 专业视角 | 发现的问题 | 本轮处理 |
| --- | --- | --- |
| 系统架构 | 子任务创建和归属持久化之间存在取消竞态；可能遗留后台计算 | 派发、归属绑定和工具调用记录原子发布；补充取消竞态回归 |
| 系统架构 | 生产重试可能丢失传感器、单景与观测版本 | 保留并深复制source_id、scene_id、observation_ref；原来源不静默切换 |
| 系统架构 | 分类缓存与答案存在固定2021/类别40假设 | 按产品、年份、类别、来源和面积方法隔离；旧结果缺少新字段时保守兼容，不改写旧答案 |
| 政府业务与架构 | 已有选区的普通农田提问可能误用仙桃全市历史基准 | 普通选区面积/分布问题走选区工具；市县口径不明先确认；整市诉求不能用小窗代答，2024选择不回退2021 |
| 视觉与信息设计 | 直接提问入口不够明显，能力卡的性质不易区分 | 地图常驻提问框和提问按钮；区分年度分类、光谱计算、仅目录、模型预报和用户图层统计 |
| 视觉与信息设计 | 等待补充条件时，新业务问题可能混入旧问题 | 明确新问题操作，完整新需求独立提交；日期/范围补充继续保留原问题与引用链 |
| 政府业务 | 未接入工程、渔政、产业等业务容易被理解为已经运行 | 六类业务接入准备清单说明所需台账、接口、可回答问题与解释边界；全部明确待真实业务数据接入 |
| 政府业务与架构 | 只有散文件不利于成果移交与复核 | 一键成果包包括中文业务摘要、原始需求/选区、来源/方法/质量、GIS、明细与逐文件SHA256；缺失或变化的文件不作为完整包发布 |
| 遥感科学 | 2021参考数据较旧，不能满足较新年度参考诉求 | 新增IO Annual LULC 2024官方公开STAC/COG原生读取，与WorldCover2021显式区分 |
| 遥感科学 | 云、缺测、年度与季节、不同面积口径可能误读 | IO云/缺测为未知；具体月份、日期窗口、季节识别不由年度产品代答；IO为UTM投影面积，WorldCover为WGS84椭球像元面积 |

## 遥感实际验证及解释

仙桃参考界内选区`[113.08,30.43,113.09,30.44]`，IO2024实际读取原生10米分类：7365个作物像元、73.65投影公顷、1个四邻域连通图斑。图斑是连通类别范围，不是1块宗地。GeoJSON投回原生UTM格网回烧差异0像元，逐斑明细与栅格面积一致。

旧选区`[113.3,30.3,113.31,30.31]`在IO2024中真实为0个作物像元，在WorldCover2021中仍为22个图斑、56.5607024公顷。两套产品的定义、模型、年度和面积方法不同，不能把差额直接解释为耕地减少，也不能仅凭底图纹理认定哪套产品准确。两套结果分别存储，不相互替代。

有效分类覆盖率表示数据完整性，不是分类准确率。本轮未完成当地独立样本精度验证，也未把年度分类产品标为当期影像新识别。

## 省内复用的产品要求

1. 同一模板必须按用户确认的选区执行，不能由固定仙桃基准替代其他市县。
2. 问题、页面、任务快照和下载的年度、来源、单位与面积方法一致；省域/整市缺少真实算子时应说明缺口。
3. 可执行基础工具与部门业务接入分别展示。业务主体、工程状态、冷链容量、违法认定等需要真实台账和对应责任方。
4. 成果包对应真实共享子任务；原始需求归属明确，不能为了当前提问改写历史计算记录。

## 仍待后续接入的能力

通用模型服务按此前约定后续配置；当前问题匹配仍为有边界的工具路由。指定当期影像农田识别需要真正的分类模型、多时相输入和独立验证。SAR像元、权威业务边界和部门系统需各自满足授权与接口条件。多用户权限、独立单位工作空间、分布式队列与省域分片计算也不因本轮数据源和界面更新而自动完成。
