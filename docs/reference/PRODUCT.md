# 产品与能力边界

0.19.0增加固定观测到光谱指数和Otsu自动分区的连续分析，问答与地图沿用同一入口，处理过程按真实节点展示并可核验来源。失败后复核已成功步骤，只恢复受影响的后续。另提供归档NDVI/NDMI共同范围的Sen稳健斜率诊断，按实际日期计算；这是描述性标量结果，没有逐像元趋势图或统计显著性认定。使用与限制见[连续分析指南](../guides/ANALYSIS_WORKFLOWS.md)。

时空智能工作台将客户的地点、数据、分析问题、定量结果和核查操作放在同一张图中。主导航为地图、专题分析、任务与成果、数据及专业工具；结构化专题和文字问询共用后端执行工具。

## 客户流程

1. 搜索地点或成果，明确地图选区，或在支持的专题中选择市县参考范围。
2. 选择分析内容，确认年度、观测时段及必需条件；也可输入文字需求。
3. 系统校验来源与算法，按需检索或读取真实数据，显示处理状态和数据缺口。
4. 在地图查看结果与定量指标，点击要素或原生像元核查，下载GIS、CSV及来源包。
5. 从任务历史恢复，保存常用问题；相同输入的归档可在版本校验后复用。

地点搜索用于导航，地名点或提供方返回视野不替代行政边界。框选范围、行政参考界与上传地块分别使用；来源、年度不匹配时说明缺口，不静默替换区域或年份。

## 已实现能力

| 领域 | 当前能力 | 使用边界 |
| --- | --- | --- |
| 一张图与导入 | 影像/标准底图、中文注记、地点/坐标/成果搜索、WGS84 GeoJSON上图与属性 | 上传支持点线面，多要素、顶点和请求大小受限；底图不是光谱分析输入 |
| 年度分类参考 | WorldCover2021、IO Annual LULC2024选区耕作地图斑提取；GlobalRice20 2024水稻参考面积与分布 | 历史公开分类产品，不是当期重新训练识别、地籍或官方面积 |
| 光谱与影像处理 | Sentinel-2、Landsat 8/9原生指数；双期差值、阈值、集合均值/中位数、OLS趋势及Otsu分区 | 明确范围和日期；按定标、质量掩膜与有效观测支持统计 |
| 农业栅格分析 | 显式端元FVC、上传地块的指数或类别分区统计 | 模型假设、部分覆盖、未知及重叠单列，不作产量或灾损认定 |
| 行业台账 | 农业、林业、水利、交通22项台账场景的绑定、筛选、分组、字段汇总、几何统计、上图与下载 | 以用户提供的实际台账为输入，业务接口与字段真实性不由场景目录自动证明 |
| 作物与时序 | 实际NDVI/NDMI曲线、质量共同范围、变化候选和人工核查、样本登记与训练门槛 | 本地独立样本不足时不发布监督分类精度或面积；公开历史分类仍可单独作为参考产品使用 |
| 数据与问答 | 多源目录、资产版本、算法契约、本机Codex受控规划、来源及下载追问 | 目录命中不是像元可用；开放问题仍受已实现工具和数据条件限制 |

专题数量由`GET /api/applications`返回，数据源与接入状态由`GET /api/data-sources`返回，实际本机归档由`GET /api/agriculture-atlas`返回。新克隆仓库不含原机器的业务库、影像成果或私有配置，不应把原机器的成果数量写成所有安装环境的固定能力。

## 共用数据源与按需调用

文章列举的EARice10、GlobalRice20、LGISer-CFD和CN_Wheat10作为平台共用来源登记，可在不同地市复用元数据和相同的分析适配。系统在收到分析需求后，再按目标、范围、年份与用途校验并读取所需数据。

目前GlobalRice20仅2024年具备执行适配。其他产品及2015年GlobalRice20的下载、认证、许可或算法适配条件尚未完成，页面保留“已登记 / 未连接”及具体障碍。仅查看目录不会下载像元或生成分析成果。

单次光谱分析、集合处理和行政全域分类各有计算上限，以专题与能力接口为准；超限提示缩小范围，不降采样冒充完整原生统计。公开产品的全球覆盖声明不保证任意地市、年度或作物都存在有效数据。

## 结果的业务含义

- 光谱指数、差值与阈值区域是核查线索，有效覆盖率是数据支持程度，均不等于分类精度。
- 公开年度Crops、Cropland及水稻类别不等于当期官方耕地、播种、永久基本农田或高标准农田统计。
- 连通图斑不是确权宗地；公开地址候选不构成完整主体名录；项目计划不等于已建成或已验收。
- 缺测与有效范围内的零命中分别保存。地图PNG用于阅读，原生GeoTIFF与来源清单用于定量复核。
- 本地监督作物分类必须具备经过核实、年度与物候适配、训练验证隔离的样本；其他地区样本或既有模型产品不能直接作为当地独立真值。

实时监管接口、权威工程与地籍边界、北斗作业轨迹、物联网实测、省域分布式计算、多租户权限和外部应用市场仍需专项接入与建设。现行指南与接口分别见[文档导航](../README.md)和[API参考](API.md)。

## 农业业务闭环

农业业务入口提供种植、畜牧、水产、工程和示范台账建档，较大GeoJSON分批入库、分页和空间索引查询，状态/进度更新，以及人工事件范围核查、核查派单、现场回执和审核归档。生产指导支持人工编制、审核发布和执行回执。九项建设内容明确标记可建档、可执行本机流程、待接口或预留；几何相交不能认定受灾，人员字段不能代替组织身份认证。当前行为和限额见[农业业务指南](../guides/AGRICULTURE_OPERATIONS.md)。
