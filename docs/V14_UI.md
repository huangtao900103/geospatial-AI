# V14 选区耕作地标注界面

用户在同一张地图框选分析范围，选择“选区耕作地标注”专题，或用文字提出标注需求。服务端负责数据读取、原生分类提取、连通图斑生成和面积统计，前端按任务实际状态显示进度。

## 数据含义

本轮可执行的是 ESA WorldCover 2021 v200 中类别 40（Cropland）的选区提取。专题表单始终显示“2021年耕作地 · 历史分类产品提取”，结果质量卡再次显示产品年度和方法，不把历史产品描述成当前影像的新识别。

10 米为产品标称分辨率。图斑是同类别像元的连通范围，不是确权宗地或农业调查地块；覆盖率是有效数据完整性，不是分类精度。尚未完成选区独立样本验证，界面不显示虚构准确率。

## 地图与成果

- 绿色矢量图斑表示服务端返回的全部耕作地连通范围，虚线表示用户选区。界面不筛掉小图斑、不合成额外地块。
- 悬停显示图斑编号与产品年份；点击显示编号、面积、像元数、选区合计与图斑数量。点击“查看结果与下载”可返回关联任务。
- 若结果没有耕作地，地图保留选区范围，面积和图斑数量按真实零值呈现。
- 打开“核查像元”后，点击图斑或选区内其他位置，读取归档的原生分类栅格，而非屏幕颜色或底图瓦片。
- 右侧结果沿用统一下载入口，文件由后端归档提供；问答历史、独立成果中心与搜索恢复接受 `result_ref.type = cropland`。
- 地图保留 ESA WorldCover / modified Copernicus Sentinel data / CC BY 4.0 署名。

## 真实浏览器验收（2026-11-14）

使用独立 Playwright 会话 `cropland-v14`，访问本地隔离预览 `http://127.0.0.1:8017`，未写入正式数据库。

1. 从耕作地专题表单的坐标入口设置范围 `[113.3,30.3,113.31,30.31]`。
2. 展开文字入口，原样输入“要把某一选定区域内的农田通过遥感影像全部标注出来”，按 Enter 提交。实际生成 `question_6dbba8dd3fc846` → `cropland_86bb4261280444`，五步处理完成。
3. 页面显示 22 个图斑、56.5607024 公顷 / 848.410536 亩、7638 个耕作地像元、100%有效分类覆盖。
4. 实际点击 `crop-000005` 显示其 42 个像元、约 0.31 公顷；开启像元核查后同点读取归档栅格，返回类别40、2021年、行12列5。原透明选区覆盖图斑的问题在此真实点击中发现，已用独立 Leaflet pane 修复，并重新点击验证。
5. 点击页面下载 GeoJSON 与 GeoTIFF，保存到 `output/playwright/v14-cropland-downloaded.geojson` / `.tif`。独立读取得到22个Polygon、7638个类别40像元，矢量面积与栅格行权重复算均为56.560702399704公顷。
6. 在地图搜索框输入“选区耕作地”，点击真实保存成果恢复。页面刷新后恢复同一问答及22个图斑。
7. 1440×1000、390×844 视口检查中，文档宽度分别1440、390，无横向溢出。移动端可收起结果面板查看地图。

截图位于 `output/playwright/v14-cropland-result-desktop.png`、`v14-cropland-patch-desktop.png`、`v14-cropland-pixel-desktop.png`、`v14-cropland-result-mobile.png`、`v14-cropland-map-mobile.png`。下载复算证据为 `v14-cropland-download-verification.json`，真实问答记录为 `v14-cropland-browser-question.json`。

独立预览最初载入时，已有的天气模型请求返回502；耕作地执行、图斑、核查和下载均成功。该外部天气服务错误不计为农田分析成功证据。

最新后端重启后，再从专题表单点击“运行分析”生成 `question_3b5e974d555846`，成功复用原 `cropland_86bb4261280444`。新结果文件类型已正确显示 geojson / geotiff / csv / json / png；点击“来源说明→本次实际用源与后续缺口”弹出真实任务来源证据，明确显示 WorldCover2021 与原任务编号，未产生额外遥感任务。完整验收索引为 `output/playwright/v14-cropland-browser-validation.json`。


## 正式页面二次效果检查与修正

2026-11-14，使用新的可见浏览器会话直接检查正式8016服务，手动搜索坐标、点选地图两个对角，再原样输入需求并按Enter。真实新选区任务`cropland_75e05e673bc749`得到24个图斑、112.21582433715682公顷、15154个耕作地像元；该选区与前一轮22图斑选区不同。

现场发现并修正：像元弹窗被顶部工具条遮挡；手机弹窗被右侧工具列遮住；手机“查看地图”没有收起结果面板；首屏指标和下载入口不够直观。修正后首屏并列面积（两位小数）、图斑数、有效覆盖和下载按钮，冻结条件折叠保留，地图常驻分类年份与底图时相提示。

实点验收：桌面弹窗顶边203px，位于工具条底边188px之下；390手机弹窗x20—316px，右工具列从337px开始，弹窗顶部188.57px位于工具条底部174px之下，关闭按钮和完整内容可见。桌面1440与手机390均无横向溢出。

真实点击下载GeoJSON和GeoTIFF，独立回烧差异0像元。地图首页原先会自动查询固定仙桃位置天气，外部服务出现过502；现改为客户发起天气查询时按需调用，保留真实失败提示，未据此声称天气接口已经稳定。最后重载页面控制台0错误。

正式截图：`output/playwright/effect-v14-final-desktop.png`、`effect-v14-fixed-mobile.png`、`effect-v14-mobile-pixel-final.png`。结构化验收：`effect-v14-formal-review.json`，下载复核：`effect-v14-download-proof.json`。
