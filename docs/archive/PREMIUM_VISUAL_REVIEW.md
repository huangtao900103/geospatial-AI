# 空间工作台整体视觉升级

> 历史记录：本文保留原阶段的设计、实现和验收口径。路径、数量与能力可能已变化；当前说明见[文档导航](../README.md)、[API参考](../reference/API.md)和[架构参考](../reference/ARCHITECTURE.md)。

## 联合评审

视觉总监、政务产品与地图/遥感专家分别审查后，共同指出：原界面的深蓝导航、亮白顶栏、深蓝地图控件和暖白内容面板风格割裂；专题目录偏文字清单；细成果线和小字号图例不够突出。当前迭代因此调整整屏构图，而非仅修改局部颜色。

采用深墨青外壳、象牙白内容、浅玉主操作。主色为#102A2D、#2F7068、#C6E4D8，内容底色#F6F7F2，正文#243936。辅助正文采用#61746E，与内容底色实算对比约4.61；浅玉与深墨对比约11.14。颜色规范用于界面，不覆盖遥感或分类数据的科学色标。

## 实施

- 新增workspace-polish.css，集中管理整屏样式。顶栏与侧栏统一；地图内嵌12px、18px圆角，大屏工具条与专题面板顶部对齐。手机采用6px内边距与15px圆角，保留可用内容区域。
- 地图搜索与主动作统一44px桌面控件，分组工具采用同一材质。主操作浅玉，次操作深墨玻璃，保留键盘焦点及减少动画偏好。
- 行业入口使用原创叶片、树冠、水纹与路径SVG，保留真实启用数。应用以双列卡片、业务示意线图、标题与用途展示；能力标签由实际注册工具生成，不把天气参考或影像查询冒称像元分析。
- 精简目录重复标题，保留搜索、勾选配置、真实历史标记及全部既有工作流。SVG仅作界面示意，不是实际地块或业务空间数据。
- 场景线要素3px、面边界2px与轻透明填充，悬停强调后恢复；不增要素、坐标或数据类别。NDVI、分类栅格及色标不变。
- 地图工具分为缩放定位、阅读导出两组，原七项操作保留。场景图例以图层名、真实数量及面积/长度单位、类别与来源组织，保留未去重及非风险评级说明。

## 实测

node scripts/check.cjs：440项检查通过；既有前端回归8项与阅读回归11项通过；另有地图7类专项检查通过，覆盖样式分层、原始指数色、图例转义、计数与坐标不变、悬停恢复及操作保留。

桌面1440×1000：顶栏64px；地图x90/y76，1338×912；面板x987/y167，420×796；工具条同为y167，右沿967，与面板留20px。1024×768：面板在画布内，工具条底部211px、面板顶部229px，不重叠。390×844：顶栏58px，地图高774px，首行卡片名称可见，无横向溢出。

实际浏览器复核跨行业搜索、场景卡进入、台账/遥感切换、查看地图、3px成果线和阅读图例。数据页保留浅底正文，避免全局深色外壳造成暗字落在暗底。正式库只读扫描0个样例候选，未修改业务数据或密钥。

测试时天地图有短暂503瓦片响应，原有重试与状态提示保留；未将其归为应用脚本错误或冒称接口永不失败。截图在等待实际底图加载后获取，没有用虚构底图替代。
