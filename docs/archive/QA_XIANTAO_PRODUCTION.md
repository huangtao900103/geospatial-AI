## 1. 实际交付范围

`data/agriculture-atlas/` 当前有12份仙桃成果清单：1份IO2024全市年度分类、1份跨产品核查、4份2026光谱成果、5份公开地址候选、1份官方项目公告事实卡。多个场景可以引用同一真实成果，不因此增加独立观测或业务数据数量。使用公开数据实际生产，不用底图截图、随机样本或代表性选区代替全市统计。

所有“全市”空间统计均采用既有geoBoundaries gbOpen的**2017年公开参考仙桃市界**，原始约72个顶点，WGS84 bbox为`[112.921612131,30.093880321,113.831989390,30.536771949]`。投影前对边界加密，像元按中心是否落入多边形纳入；不把bbox矩形当作市界。它不是现行权威行政界、确权宗地或项目工程边界。

参考多边形元数据面积约2511.38平方千米，IO10米中心格网面积2512.5794平方千米，Landsat30米中心格网面积2512.566平方千米。投影、边界加密及像元离散规则不同会产生差异，未按外部统计面积强制缩放。

`https://io-10m-annual-lulc.s3.us-west-2.amazonaws.com/49R_2024.tif`

## 3. 跨源耕作地核查参考

生产模块为`city_cropland_agreement.py`，入口为`scripts/produce_xiantao_agreement.py`，版本`city-cross-product-review-1.1`，目录为`data/agriculture-atlas/xiantao-cropland-review/`。

输入是既有真实WorldCover2021原生EPSG:4326分类文件与上述IO2024分类文件。两份输入只读，记录并核对SHA256；以IO2024原生10米格网及其市界mask为参照，仅将WorldCover2021按最近邻对齐。GDAL变换容差固定为`1e-9`像元，防止默认近似变换在类别边缘选择相邻像元。不是把分类图双线性插值后再分类。

| 同一10米比较格网的核查类别 | 像元数 | 面积（公顷） |
| --- | ---: | ---: |
| 两产品均为作物/耕作地类别 | 11,105,126 | 111,051.26 |
| 仅IO2024为作物类别 | 1,579,575 | 15,795.75 |
| 仅WorldCover2021为耕作地类别 | 5,622,848 | 56,228.48 |
| 两产品均为其他已知类别 | 6,815,364 | 68,153.64 |
| 任一源未知或对齐边缘 | 2,881 | 28.81 |
| 合计 | 25,125,794 | 251,257.94 |

未知不并入“均非”或差异，28.81公顷也可能来自两产品像元中心市界掩膜的对齐边缘，不能解释成实际云量或未调查。`analysis.tif`保存核查类别、市界mask、IO原类别、对齐后WC类别、共同有效mask共5波段；另有全类别图、差异候选图、类别及逐行CSV。

独立审计遍历180个输出块，以另一套分类表达式逐像元复算全部5波段；原IO类别及市界mask一致。又按参考像元中心直接反查原WorldCover格网，16,384个样点全部一致；逐行CSV和汇总一致，输入SHA不变。证据为`output/xiantao-agreement-proof.json`和成果`result.json.validation`。

**这是跨年、跨模型、跨类别定义的核查筛查，不是耕地变化检测、增减面积或准确率评估。**两产品交集不等于真实农田面积。WorldCover2021原生面积167,296.8847公顷（约250.95万亩）、IO2024原生面积126,865.22公顷（约190.30万亩）分别保留；共同格网核查值不替换各自原生面积，两者差值不得解释为真实耕地减少。

## 4. 2026实际观测光谱产品

模块为`city_spectral.py`，入口为`scripts/produce_xiantao_spectral.py`，4份目录为`xiantao-2026-spectral-{ndvi,ndmi,mndwi,change}`。实际来源是USGS/NASA Landsat8/9 Collection2 Level2地表反射率公开COG，经Microsoft Planetary Computer目录查找资产；不是调用Google Earth Engine云算力，也不是把天地图RGB底图作为NIR/SWIR输入。

请求前期为2026-09-01至09-30，后期为2026-10-01至11-14。实际前期观测为**2026-09-13**（Landsat9），后期为**2026-10-07**（Landsat8）。更晚10月31日候选的市界QA有效覆盖约39.02%，未达本轮70%门槛；10月7日约99.96%，因此按实际候选选择10月7日，不标成11月15日实时监测。

原生EPSG:32649、30米，市界内2,791,740个像元，251,256.60公顷。按实际资产scale/offset定标，剔除QA_PIXEL位0至5、所有非零QA_RADSAT、负反射率、非正分母和缺测。变化严格为后期NDVI减前期NDVI，仅共同有效像元参与。

| 已生产产品 | 实际观测 | 有效像元数 | 最终有效覆盖 | 全市有效均值 |
| --- | --- | ---: | ---: | ---: |
| NDVI植被光谱 | 2026-10-07 | 2,790,688 | 99.9623% | 0.445820 |
| NDMI植被水分线索 | 2026-10-07 | 2,790,572 | 99.9582% | 0.138242 |

4份导出均保存实际已定标输入、QA及有效/市界/2024Crops参考mask，另有统计、全有效像元直方图、来源和`validation.json`。独立校验重新打开栅格，每份核对全部2,791,740个市界像元、公式、质量掩膜、未知、源SHA、历史分层、均值及CSV，公式最大绝对误差均为0。该结果验证文件和计算一致，不构成地面真实性或分类精度验证。

2024Crops最近邻到30米只作历史参考分层，共1,409,260个参考像元。它不能确认2026仍是农田，也不能当作2026播种面积。NDVI/NDMI不直接输出作物品种、产量、实测土壤含水率、灾损或旱情等级；MNDWI阈值不认定养殖塘、黄鳝、尾水达标或禁捕违法。本轮未生产EVI2全市成果、连续逐日序列、多景时间合成或作物分类模型，能力列表存在算法不等于该场景数据已经生产。

## 6. 应用接入与尚未实现的业务闭环

已生产的分类、光谱、核查、地址和公告通过农业Atlas清单供场景复用，保留来源、时相、分辨率、限制和可下载产物。预生产参考数据可用于查看与核查线索；用户业务台账的场景统计是另一条明确输入流程，不能把公开参考或地址候选冒充授权台账。

现有场景台账处理支持已上传真实要素的筛选、分组、主体去重、明确单位的数值汇总、面几何面积及LineString轨迹长度，保留原属性、输入版本和来源。面面积逐要素相加，未做跨要素空间去重；轨迹长度不推算作业面积。高标准农田/确权需面数据，农机轨迹需已有LineString，不能凭机构点位或离散点自动认定工程/作业范围。

尚未接通的授权数据包括工程与验收台账、权属/延包、农机设备实时轨迹、有效禁捕监管水域与船舶视频事件、养殖许可/排口/水质实测、冷链容量、交易与检测接口。未生成这些资料或监管结论。通用模型服务仍未配置；已登记的固定服务、结构化规则及真实处理链路可执行，不应描述成已经具备任意开放问题的完整自主业务判断能力。
