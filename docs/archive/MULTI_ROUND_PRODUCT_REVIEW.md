# 多专业交叉评审与修复记录

> 历史记录：本文保留原阶段的设计、实现和验收口径。路径、数量与能力可能已变化；当前说明见[文档导航](../README.md)、[API参考](../reference/API.md)和[架构参考](../reference/ARCHITECTURE.md)。

本轮由独立架构与政务流程、遥感科学与数据工程、前端与可用性三个评审分工，以及主集成负责人共同执行。评审不以既有测试通过作为结论：先独立复现，再修复，再由其他分工使用反例交叉检查，最后进行正式服务验收。

验收范围是当前公开遥感产品、已登记真实算法、GeoJSON业务范围、区域成果读取及一张图操作；没有把未配置的通用模型或未授权的监管系统算作已接通能力。“无阻断”指该范围内发现的问题已关闭，不是地面精度认证或对所有未来需求作保证。

## 第二轮：修复与交叉反例

跨分工复核继续发现并关闭：具体镇/村、城区/方向片区的请求误用全市；全年/逐月/季度请求误用单景；把农机服务地址当设备位置；实际市界外valid_mask为NaN导致区域FVC拒绝；没有有效支持时阈值面积误报0；当前产品来源追问继承隐藏旧q；把有效数据覆盖率当类别占比。最终连续操作还复测地图与问答焦点恢复、切换图层清除旧像元浮窗、来源/下载答复前置，以及手机搜索层级。

规则遇到范围、日期、指数、来源或统计周期不匹配时返回补充条件/不支持，不使用另一个年份、另一个地区、单日代全年或Crops代法定地类。重新计算不伪装成读取旧成果；当前全市批量重新生产仍使用受控生产脚本，网页归档读取会明确其操作性质。

区域农业复用通过了真实数据链路，而非只用小型fixture：隔离工作区复制真实NDVI与IO源，使用应用模板→问答→执行→农业服务计算FVC；显式验证端元0.2/0.8没有冒称本地校准。对2,790,688个有效像元独立复算，float32导出最大误差约1.99e-8。另对真实影像上明确框选的验证范围，在原42,185,312像元分类矩形中仅读取22×22窗口，234个Crops像元为2.34公顷，与全格网独立计数一致。该框选不是确权地块或新增农业台账。

证据为`output/review-rounds/actual-native-reuse-proof.json`与可复现脚本`scripts/verification/verify_regional_reuse.py`。所有新验证问题/数据保存在隔离工作区；正式浏览器联测仅允许真实产品的少量问询，使用唯一请求ID，不写样例数据。
