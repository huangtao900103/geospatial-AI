## 方法与来源

实际研读OpenGE官方应用开发/案例页面中的CoverageCollection、固定算子与数据流程组织；首页网页工具超时后通过普通HTTPS成功读取。研读Google Earth Engine官方ImageCollection reduce、回归与直方图文档。实现为本机固定Python/Numpy/Rasterio算法，公开数据通过已有PC S2/Landsat源取得，不宣称已接通OpenGE/GEE云算力、取得其专有实现或拥有其数据。

本轮新增四算法，前端收在“更多分析 → 时序与影像处理”两个卡片，不新增导航。模型工具契约新增处理与状态查询，仍为固定服务调用，不执行自由代码/URL；未配置通用模型服务。

真实调用链：`application-runs → assistant → execution → raster_processing → 固定PC目录与COG → 原生统计 → GIS/来源/ZIP`。测试范围`[114.2,30.5,114.21,30.51]`，窗口2025-10-01至11-30，S2 NDVI，最多4独立日期、景云量≤30。它是算法核验选区，不是仙桃市行政界或实测农田，不据此给出农业专项认定。

前三项实际四日期为2025-10-05、10-28、11-21、11-29。同一原生参考格网按最近邻对齐，每景独立质量掩膜；均值/中位数需≥2次有效观测，趋势需≥3次独立日期。缺测和支持不足为null/NaN/透明，不填0；趋势按真实UTC天数求OLS斜率/截距/R²，不称显著性或长期趋势。逐景均值的空间支持变化与固定共同支持统计分开。每次选择的具体场景、窗口哈希和定标保存在冻结来源中，重试不重选场景。

核心专家另以五个公开真实case逐像元独立复算，包括上述三归约、Landsat9 EVI2三景30m、S2 NDRE两景20m；输出值最大差0，R²最大差约1.46e-11。Otsu另验证真实源、带孔四邻域、小斑块剔除、above>=与below<互补、原生回烧、0与未知。详`output/v18-collection/independent-proof.json`及`V18_OTSU_REVIEW.md`。

四个正式成果包均真实HTTP下载，CRC与36个SHA256清单条目逐项验证；逐文件端点也可读。四次来源追问保持原任务ID，不创建替代计算。正式证据：`output/v18-review/formal-processing-proof.json`，可复用脚本：`scripts/verification/verify_processing_http_v18.py`。
