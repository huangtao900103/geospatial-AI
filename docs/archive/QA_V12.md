## 本轮交付

| 能力 | 入口与行为 | 验收范围 |
| --- | --- | --- |
| 影像/标准地图+中文注记 | 图层面板两种组合，底图/注记独立状态；同源后端代理 | 无Key状态与模板、安全协议测试；有Key瓦片待验证 |
| 地名地址搜索 | 地图输入联想本地，Enter/搜索按钮提交在线；保留持久化成果搜索 | 本地实际检索、协议合并/断网回退隔离测试 |
| 坐标地址查询 | 地图底部‘查地址’，仅显式请求中心坐标 | 无Key配置导向、逆地理协议/错误隔离测试 |
| 行政区V2 | 服务卡名称/行政码→候选或建议→查看独立参考层/GeoJSON下载 | WKT结构、孔洞/多面与错误输入；真实授权几何待验证 |
| Key配置与检查 | 地图/数据配置入口；私有文件0600，保存与检查分开 | 本机HTTP安全边界、清除、并发generation、无Key不假成功 |
| 多源目录 | 地图/地名/行政界三项服务登记 | 不列为可计算光谱像元或已实现省域分类 |

## 自动与专家核验

- 全量自动检查：246项，21.624秒；完整输出见[v12-check.txt](../../output/playwright/v12-check.txt)，实际运行耗时以该输出为准。包含原214项、27项天地图协议/私有配置/行政/WKT/回退及并发测试、5项HTTP集成边界。
- 专家独立14项WKT输入审查通过：[v12-architect-boundary-audit.json](../../output/playwright/v12-architect-boundary-audit.json)。所有输入均明确为解析用例，不是现场边界。
- 官方文档/匿名WMTS元数据实际访问与摘要：[v12-official-source-audit.json](../../output/playwright/v12-official-source-audit.json)。GetCapabilities无Key200不证明GetTile授权已通过。
- HTTP测试在临时数据库和独立私有配置目录执行，未将测试Key写入正式工作空间，亦未用测试Key访问外网。
- 固定官方域名、禁止带Key跳转、受限并发和大小、错误脱敏；GET状态、map/config、health、data-sources、bootstrap不下发Key；配置不增加通用业务records。

## 浏览器验收

隔离8017预览环境，桌面1440×1000、手机390×844；使用独立浏览器会话，不切换用户当前页面。四服务真实显示待配置，点击未配置底图/查地址进入配置；官方申请链接准确。非法Key后端400拒绝、输入清空，password控件，本地storage和URL无Key。未配置行政查询明确禁用，当前既有地图和专题入口可用。

人工代码复核并关闭：仅行政suggestion也展示可继续查询候选；连接检查verified/partial与数据目录证据一致；前次保存天地图视图但当前Key缺失时，初始化/恢复改选可用底图，不以配置弹窗替代地图。前端详细记录与截图见[V12_UI.md](V12_UI.md)。

## 后续授权验收

本人/单位账户管理员在[官方控制台](https://cloudcenter.tianditu.gov.cn/center/development/myApp)完成认证与许可申请，在本机“数据→天地图服务”输入Key。按四服务逐项检查，其中tiles分别检查img/cia/vec/cva，检查失败保留原因。应用信息与配置方法已在[TIANDITU_SETUP.md](../guides/TIANDITU_SETUP.md)准备。

天地图WMTS不是NIR/SWIR/SCL计算输入；地址POI不能当监管完整底数；公开行政轮廓不是确权边界或当期耕地分类。省域现状统计、多景合成、农业分类精度验证仍按独立研发能力验收，不因有菜单或取得边界宣布完成。
