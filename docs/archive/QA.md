## 结论

本轮本地工程版的服务端核心闭环通过独立黑盒核验：多业务需求解析、不可变运行参数、示例空间统计、任务终态与重试、重启恢复、应用发布及副本复用均表现符合本轮范围。未发现仍阻断本地试用的服务端问题。

桌面/移动浏览器、视觉与组件预览验收由主负责人另行记录于 `BROWSER_QA.md`，本文件不将其提前标为通过。真实大模型、遥感解译和对外共享未在本轮接入。

## 核验环境与隔离

- Python 3.9.6，标准库 HTTP 客户端与 SQLite；独立服务绑定 `127.0.0.1` 的随机空闲端口。
- 每轮使用系统临时目录中的数据库，未使用或修改正式 `data/`，未启动、停止或替换 8016 服务。
- 黑盒通过 HTTP 请求创建计划、启动/取消/重试任务、发布/克隆应用、查询成果与重新启动临时服务。
- 重启中断测试强制终止的是 QA 自己启动的临时进程；再以同一临时数据库启动，检查历史状态。

## 发现与复验

1. **集成 URL 空凭据字段**：初版 `?token` 与 `?Authorization=` 会因解析器丢弃空值参数而被接受。已通知工程师改为保留空值并检查键名。独立复验上述两个地址以及 userinfo、api_key 地址均返回 400。
2. **静态 GET/HEAD 边界统一**：初审建议 GET/HEAD 复用目录约束并校验 symlink 解析后路径。修复后以临时外部文件和临时 symlink 黑盒验证，两种方法均返回 404。
