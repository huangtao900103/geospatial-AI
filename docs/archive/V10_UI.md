# V10 通用一张图与光谱算法界面

> 历史记录：本文保留原阶段的设计、实现和验收口径。路径、数量与能力可能已变化；当前说明见[文档导航](../README.md)、[API参考](../reference/API.md)和[架构参考](../reference/ARCHITECTURE.md)。

本轮前端承担省内推广复用的通用品牌，以及真实多光谱能力的可理解呈现。未改真实成果的区域、日期、来源或数值，也没有将通用页面名称解释为全省数据已接入。

## 两轮专家讨论

第一轮与架构/遥感专家确定：平台主入口应通用，具体区域与业务口径归每次分析输入、来源与成果；客户继续以地图提问和必要澄清操作，数据供应商、公式与波段不进入客户必填流程。

第二轮确定：后端`GET /api/production/capabilities.indices`是指数名称、公式、所需波段、参考格网尺度、版本、可用性与局限的唯一声明。客户端不硬编码算法已全部可用，不把20m SWIR参考格网包装成10m；MNDWI/NDWI等仍是光谱指数，不称自动水体分类，NDBI不称建成区分类，NBR不称火灾/灾损识别。

## 品牌与范围

- 首页主标题改为“时空智能一张图”，英文为“GEOAI SPATIAL INTELLIGENCE WORKSPACE”，标签为“智能分析”。
- 地图复位入口改为“返回验证区域”。已有仙桃问题、区域边界、数据源、产品年份及结果原样保留。
- 客户欢迎页通过折叠“当前能力与数据范围”说明边界；常用能力明确全市分类面积目前为仙桃2021产品/2017参考界，选区光谱按实际公开影像覆盖执行。

## 算法与结果接线

- 客户常用能力增加由`indices`生成的折叠光谱指数入口，展示真实可用状态、公式及参考尺度；点击只生成业务问题，仍由后台自动组织执行。
- 专业遥感页增加折叠“指数与数据要求”，各卡显示公式、所需波段及其原生尺度、目标参考格网、局限和方法依据。
- 专业高级参数的指数选择从同一元数据生成；`index_id`随所选历史任务继承，不以修改需求覆盖原任务。
- 新的真实COG任务显式提交`sampling=native`；人工样本仅NDVI，不把其他指数送到旧代表采样模式。
- 客户质量卡与地图图例按`summary.index`/`provenance.algorithm`显示实际指数名、公式及参考波段/尺度，旧NDVI任务保留兼容。
- 专业结果读取`mean_index`，NDVI旧字段只作历史后备。单期指数阈值可为负，最终范围按后端目标校验。范围描述本身不会让默认阈值面积抢占单期指数主指标。
- 专业导出优先列出真实GeoTIFF、配准PNG和来源JSON；历史无栅格清单的任务仍保持GeoJSON兼容。
- 版本引用更新为`20261113-v10`，地图全局品牌与结果内部区域分别呈现。
