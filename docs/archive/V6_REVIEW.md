## 1. 签审结论与交付口径

本轮真实全域核算及数值复核通过，未发现阻断当前交付的源、面积或归档问题。可交付的结果是：**2017 年公开概化参考仙桃市界内，ESA WorldCover 2021 v200 的 code 40（Cropland）分类面积基准**。它不是当前官方法定耕地保有量、播种面积、高标准农田面积，也不是本平台新训练分类器对当前影像的识别结果。

| 核查量 | 实际值 |
| --- | ---: |
| code 40 分类面积 | 167,296.884667 公顷 |
| 换算亩数（1 公顷 = 15 亩） | 2,509,453.270009 亩 |
| 占参考市界栅格掩膜面积 | 66.615750% |
| 市界掩膜面积 | 251,137.131172 公顷，即 2,511.371312 平方公里 |

| code 40 像元 | 22,585,705 |

“有效覆盖约 100%”只说明所用分类产品在这个掩膜内没有缺测，不代表分类精度 100%，不代表边界具有现势权威性。结果小数位用于计算复查；展示可取 167,296.885 公顷或约 250.945 万亩，不应将数值计算精度解释为调查精度。本地独立样本验证、分类误差校正面积及当地 95% 置信区间尚未完成；源码正确保留 `ci95=null`、`is_official=false`。

本次实际全域源读取与计算由遥感/后端专家运行，结果在 `output/xiantao-worldcover-2021/`；监督者另外进行了全部本地栅格、CSV 与面积复算，未再次下载公共 COG。下述签审覆盖源码与本地证据，不代替主负责人后续真实 HTTP 与浏览器验收。

## 2. 数据源与边界完整性

- 分类产品固定为 [ESA WorldCover 2021 v200](https://esa-worldcover.org/en/data-access)，[产品 DOI](https://doi.org/10.5281/zenodo.7254221)，许可记录为 CC BY 4.0。本次实际源为 `https://esa-worldcover.s3.eu-central-1.amazonaws.com/v200/2021/map/ESA_WorldCover_10m_2021_v200_N30E111_Map.tif`，单波段 EPSG:4326、36,000 × 36,000 原生格网、源 nodata=0。仙桃参考边界完整位于 N30E111 内，只需这一覆盖块。
- 市界使用 `data_sources/xiantao_boundary.geojson` 和配套 `.metadata.json`。来源为 [geoBoundaries gbOpen 元数据接口](https://www.geoboundaries.org/api/current/gbOpen/CHN/ADM2/)，固定提交 `9469f09` 的[完整 GeoJSON](https://media.githubusercontent.com/media/wmgeolab/geoBoundaries/9469f09/releaseData/gbOpen/CHN/ADM2/geoBoundaries-CHN-ADM2.geojson)。原始 `Xiantaoshi` 是唯一匹配要素，`shapeID=17275852B60855200621799`，1 个 Polygon、72 个顶点。来源省级字段为空；湖北归属的交叉核验方法已在元数据中如实记录。
- 源坐标声明为 CRS84，经纬度顺序保留为 WGS84 longitude/latitude；没有把 GCJ-02 边界直接套入影像。边界 bbox 为 `[112.92161213100007,30.09388032100003,113.8319893900001,30.53677194900007]`。源码每次读取核对文件 SHA-256，防止未记录的几何替换。
- 边界代表年份是 **2017**，不是 2021。元数据保留底层 PDDL 1.0、geoBoundaries 分发署名、提供者、固定源 URL、抓取时间与完整源文件指纹。经 EPSG:6933 核验的参考矢量面积约 2,511.376955 平方公里；[湖北统计年鉴参考表](https://tjj.hubei.gov.cn/tjsj/sjkscx/tjnj/gsztj/hss/202504/P020250421554816619675.pdf)中仙桃 2,538 平方公里仅用作合理性对照。二者差约 -1.049%，未通过缩放几何或统计值强行对齐；这项差值不能充当分类面积误差界限。

## 3. 原生统计方法复核

审查 `landcover_services.py` 的 `account_native` 与 `ellipsoid_row_pixel_area`：

1. 按产品原生分辨率将市界包络对齐到全球经纬格网，完整目标窗口为 **5,316 行 × 10,925 列 = 58,077,300 个包络像元**，实际读取 11 条带。源读取没有 `out_shape`、overview 或重采样，未用小窗口抽样推算全市。代码已有 `processed == width*height` 强制完整覆盖检查；缺块直接失败。
2. 使用真实 Polygon 的 `geometry_mask(..., invert=True, all_touched=False)`，采用 GDAL/rasterio 的像元中心规则，不扩张为所有相交像元。孔洞及多要素经同一布尔掩膜处理，重叠要素不会叠加计数。边界恰好穿过像元的处理服从该栅格化实现，属于像元级边缘近似。
3. 面积用 WGS84 椭球纬带积分，按每一原生行的南北纬度计算像元面积，再乘该行各类别像元数求和。公式为 `a²/2 × Δλ × [q(φnorth) − q(φsouth)]`，其中 `q(φ)=(1−e²)[sinφ/(1−e²sin²φ)+atanh(e sinφ)/e]`。这是经纬矩形在椭球上的面积，适合该原生格网。产品“标称 10 米”不意味着仙桃每个经纬格网像元都等于 100 平方米，代码没有做这个错误乘法。
4. 11 个合法类别分别累计；市界内 code 0 和未识别类别统一进入缺测/未分类计数与面积，不计入 Cropland，也不从统计分母中悄悄删除。守恒条件是 `Σ类别面积 + 缺测面积 = 掩膜总面积`。本次真实源市界内没有缺测。
5. 内部计数与面积使用原生栅格；米制换算只在最后执行：平方米除 10,000 得公顷，公顷乘 15 得亩。`cropland_share` 的分母是整个参考市界掩膜面积。

## 4. 第三方离线复算证据

监督者直接读取已归档的 `row_counts.csv` 和 `classification.tif`，不调用后端面积函数、不重新访问公共源：

- CSV 共 5,316 行，逐行验证 `total_pixels = Σclass_N + nodata_pixels`，全部通过。
- 另按 256 行读取本地原生 TIFF，使用已交付边界重建掩膜，逐行逐类计数；**全部行、全部类别与 CSV 完全一致**。这项检查与生产端共用 rasterio/GDAL 掩膜语义，因此不是一个全新栅格化算法的交叉验证；它验证了已归档 TIFF、边界与 CSV 的一致性。
- 独立面积路径采用 PROJ 的 **EPSG:6933 等积投影**：以经度 0 附近的原生经度步长求条带宽度，将每行南北纬投影为 Y 坐标，相乘得到像元面积，再对 CSV 计数用 `math.fsum` 求和。未调用 `ellipsoid_row_pixel_area`。
- 独立 code 40 面积为 **167,296.88466725237 公顷**；后端为 **167,296.88466725498 公顷**；差 **-2.62×10⁻⁹ 公顷**，属浮点舍入量级。现有 `independent-verification.json` 使用实际经度的投影坐标相减，差约 0.000033 公顷，同样远低于一个原生像元。
- 所有本地市界内像元复查合计 33,904,634，其中 code 40 为 22,585,705，code 0 为 0。包络扫描量为 58,077,300，与 5,316 × 10,925 完全一致。
- 掩膜面积与参考矢量面积差 **-0.000224708%**，与像元中心边缘栅格化近似一致；这一数值仅验证几何栅格化一致性，不证明分类精度或参考市界精度。

## 5. 配准显示与成果归档边界

`make_preview` 从已完成原生分类栅格用最近邻重投影到 EPSG:3857，生成 1,536 × 866 的 `overlay.png` 与 `classes.png`。返回的经纬 bounds 为 `[112.92158333333333,30.093833333333333,113.832,30.536833333333334]`，是原生包络的地理角点；在 Leaflet 3857 地图中按这组 bounds 放置 Mercator 图片可保持配准。预览使用透明背景及分类色，原生 EPSG:4326 GeoTIFF 保留产品、年份、类码、市界指纹、面积方法和掩膜规则标签。

PNG 是降采样显示产物，代码没有把它回灌统计。用户应可同时查看边界、code 40 分布和完整分类图，下载原生 TIFF、逐行计数 CSV 与来源报告。源码中成果 URL 绑定独立 task ID；本次不替前端宣称点击、图层配准视觉或下载行为已在浏览器通过。

## 6. 状态、缓存与错误边界

- API 为独立 `/api/landcover/tasks`，不会将全市面积任务塞进此前 NDVI 16×16 代表采样链路。公开请求只接受 `region/product/requirement`；本轮固定仙桃及 2021 产品，拒绝任意源 URL、其他产品、异地或省域替换，也拒绝请求文本中的非 2021 年份，避免默默改写用户口径。
- 每次任务有独立 ID、计划快照、五个实际节点、日志和输出目录；一个本地实例同时最多一个活动面积任务。没有将旧成功缓存伪装为新计算。成功成果按任务 ID 固定；HTTP 成果缓存 `private,max-age=3600` 适合不可变任务产物，任务 JSON 则为 `no-store`。
- 网络源、依赖、格网、覆盖、空掩膜、守恒等错误均使任务失败，未提供模拟面积或降采样估计回退。统计规模超过本机上限时明确拒绝，不能偷偷降低统计分辨率。
- 扫描条带和各阶段前后检查取消；终态保护防止后台线程覆盖 `cancelled/failed/succeeded`。取消任务不发布部分成果；重试产生新任务 ID。服务重启时将遗留活动任务和运行节点同时转为失败并记录结束时间。
- 仅 `succeeded` 任务开放预定义文件白名单；`.partial.tif`、失败/取消目录及任意路径不能通过成果接口取出。完整覆盖检查即使在本地 TIFF 形成后失败，仍不能经任务成果路由发布。
- 已只读核对 `tests/test_landcover.py` 的面积等积对照、缺测守恒、孔洞、重叠边界去重、原生标签/预览、指纹、取消终态、重试、年份/范围拒绝和重启恢复测试。测试执行证据由实现/QA 人员提供，本轮没有重复全部测试。
