# V3 独立算法与数据质量验收

日期：2026-11-12。第三轮质量专家交叉复核记录。只将实际检查或执行的内容记录为通过；界面与生产能力不由服务测试代验。

## 范围与方法

使用临时数据库和 `127.0.0.1` 随机端口的独立 HTTP 服务，核验 `datasets`、`analysis` 与固定公开服务适配器。没有操作正式 8016 服务或 `data/`。独立检查是通过 HTTP 请求和小型可复算数据进行，不依赖前端显示成功。

公开适配器的缓存、错误和格式检查采用确定性模拟上游响应；这证明适配器行为，不等于本 QA 在当时获得了真实公开天气或影像。真实接口访问由架构师及平台工程师另有记录。

## 交叉复核发现与修复

1. **巨大整数500**：`math.isfinite(10**1000)` 会溢出，曾导致坐标及最近邻阈值返回500。工程师为 finite 增加溢出防护，独立复验坐标422、属性422、阈值400。
2. **properties静默转换**：原 `properties or {}` 接受空数组、false、空字符串及0。已改为仅null/缺省可视为空对象，其他非对象拒绝；独立复验通过。
3. **空坐标回落仙桃**：HTTP查询解析器曾丢掉空lat/lon。已保留空值并返回400，不再默认为仙桃。
4. **无效气象格点成功**：原适配器可接受无效或缺失返回坐标。已增加有限数和范围验证；独立复验字符串/null/999/缺失均502，未伪造格点。
5. **新增溯源引起缓存回归**：增加provenance时循环变量覆盖缓存URL键，30项测试中缓存项失败。QA定位后通知工程师改为独立变量；最终复验结果见自动测试记录。

## 未代验与生产限制

- 桌面/窄屏、上传表单、图上实际范围、XSS转义、公开数据署名邻近显示由总体负责人的浏览器验收记录覆盖。
- 本 QA 的公开错误/缓存测试是模拟上游；未以此宣称第三方服务有可用性保证。
- 算法输入规模有界，只支持声明的局部WGS84几何；不提供全球跨经线修复、测绘认证或空间union。
- 真实大模型规划、卫星栅格像素调取/云掩膜/专业解译、生产身份与跨组织权限仍未接入。
