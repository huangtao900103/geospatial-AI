# V15 遥感科学审查与真实2024分类产品接入

审查日期：2026-11-14。本轮新增明确年度的分类产品执行器，保留既有WorldCover2021和光谱分析。没有将目录探针、历史分类产品或NDVI阈值称为当期农田新识别模型。

## 科学审查结论

当前平台真实具备三类相互区别的能力：原生S2/Landsat光谱指数计算、公开年度分类产品提取、明确用户矢量上的空间统计。它们的输出不能互相代替。NDVI/NDWI等指数本身不能证明农田、作物类型、灾损或法定用途；产品分类也不能自动变成确权宗地。当前没有本地独立样本验证，不能给选区虚构识别准确率和面积置信区间。

原2021分类功能的数据较旧。本轮把已核验无需账号的Impact Observatory / Microsoft / Esri Annual LULC 2024从“探针可读”升级为完整的选区原生读取、未知区处理、连通图斑、面积与GIS归档。2024依然是历史年度产品，不是2026现况或客户指定任意时段的新分类。

## 官方依据与产品契约

[AWS官方开放数据注册页](https://registry.opendata.aws/io-lulc/)列出2017—2024年度、10米、九类、Sentinel-2年度预测合成、CC BY4.0和公开S3无需AWS账号。2024年度于2025年6月发布。本轮没有把总体精度声明推导为仙桃局部精度。

实际查询固定[官方STAC集合](https://api.impactobservatory.com/stac-aws/collections/io-10m-annual-lulc)，2024仙桃选区命中`49R-2024`。提供方类别声明为：0 NoData、1 Water、2 Trees、4 Flooded vegetation、5 Crops、7 Built area、8 Bare ground、9 Snow/ice、10 Clouds、11 Rangeland。类别5为本轮提取目标；0、10及未知类别都不计入有效分类覆盖。云不能当作非农田。

- 产品ID：`io_lulc_2024`；来源ID同名；产品年份2024；类别代码5。
- 固定COG域：`io-10m-annual-lulc.s3.us-west-2.amazonaws.com`；固定命名`<supercell>_2024.tif`。
- API请求不接受任意URL/文件路径。目录响应、集合、年份、资产域、文件名、UTM声明及实际TIFF10米格网均要核验；不得静默换年、换源。
- 当前只处理一个IO瓦片和一个UTM格网完整覆盖的选区。目录返回多瓦片、实际栅格范围不足、格网不符时明确失败；不降采样或用小窗冒充全区。

## 原生面积和GIS口径

IO原生GeoTIFF使用WGS84 UTM投影。本轮读取原生10×10投影米像元，不读取overview或重采样；将WGS84选区边界每边加密32段投影到UTM，再用像元中心掩膜。输出GeoTIFF第一波段为`classification`，第二为`aoi_mask`；类别0和选区外因掩膜可明确区分。

面积方法标识为`native_utm_projected_grid`，单像元100投影平方米。这与WorldCover2021的EPSG:4326逐行椭球面积是两个明确不同的方法，不能混写；投影面积也不能当法定调查面积。GeoJSON使用EPSG:4326，保留原生四邻域连通范围与孔洞，不简化、不滤小斑；像元轮廓可越选区约半像元。

图斑数是分类连通范围数量，不是宗地或现实田块数量。较大连续农作物覆盖可能只有一个图斑；这不是漏画宗地。若存在云或缺测，报告的作物面积只是有效分类像元中观测到的作物覆盖，未知区域不能按零农田处理。

不同产品的训练、类别体系、格网和面积方法不同，**不能直接把WorldCover2021与IO2024面积差当作耕地增减**。

### 非零分类与完整GIS案例

选区`[113.08,30.43,113.09,30.44]`的中心位于项目既有仙桃公开参考界内。实际官方读取并完成服务，约4.50秒：

- 原生CRS EPSG:32649，像元10×10投影米，窗口113×99。
- 选区10,649像元，有效分类覆盖100%；Crops5为7,365像元。
- 1个四邻域连通分类图斑，参考面积73.65公顷，1104.75亩。保留内部孔洞与全部类别5像元。
- 导出GeoJSON投影回原生格网回烧，差异0像元；逐斑CSV像元数和面积守恒。
- 独立对重投影回UTM的几何作平移后的鞋带面积计算，736499.9999998457平方米，与格网报告736500平方米差约0.000000154平方米。
- 另用EPSG6933等积参考计算约736360.098平方米，说明UTM投影面积与椭球/等积面积确有差异；本报告不把它们混称为同一方法。

记录：`output/v15-io/nonzero-task.json`、`independent-proof.json`，任务`cropland_3c68161bdbef4a`，产物在`output/v15-io/real/<task_id>/`。以上记录使用独立内存store，不修改正式业务库。

## 仍待独立研发的能力

当期/任意指定年度的农田重新识别，需要真实影像时序、云影质量处理、已验证分类模型、未知/低置信结果和独立本地样本。后续可研究WorldCereal时序模型或Dynamic World本地推理，但必须分别解决账号/算力、L1C与L2A输入契约、模型依赖和精度验证；本轮不把这些候选标为已完成。

交叉评审发现，仅拒绝“11月/季度”不足以拦截ISO或斜杠日期窗口。本轮已统一拒绝`2024-11-01至2024-11-30`、`2024/11/01`、`2024.11.01`、年月数字窗口、中文月份、季度/Q4、季节及秋冬播/播种期等限定，即使日期仍在所选年度内，也返回`YEAR_MISMATCH`。全年模板与“当前范围”这类纯空间表达仍正常通过。新增回归同时覆盖IO2024与WorldCover2021共30个拒绝输入和4个年度/空间正例。
