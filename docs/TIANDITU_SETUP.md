# 天地图接入与许可配置

适用于V12本机工作台。**本机已于2026-11-14完成自有服务器端Key配置和全部四类服务真实验证**，见[实际验收](TIANDITU_LIVE_ACCEPTANCE_20261114.md)。以下申请步骤供新机器或更换账号使用；取得许可并通过实际请求前，不标为已联网验收。

## 申请入口与应用信息

当前官方[应用管理](https://cloudcenter.tianditu.gov.cn/center/development/myApp)、[开发者认证](https://cloudcenter.tianditu.gov.cn/center/development/developerAuth)、[注册](https://passport.tianditu.gov.cn/register)。账户身份认证需本人或单位账户管理人完成。页面名称、审核要求、配额与可用服务以当前控制台为准。

可直接使用的应用描述：

> 应用名称：经纬时空智能一张图工作台
>
> 应用用途：为省、市、县农业及空间业务提供统一地图工作台，按需调用天地图影像底图、标准地图及中文注记，提供地名地址搜索、坐标地址查询和行政区划参考范围展示。遥感指标计算使用单独授权的原生观测数据，不以浏览瓦片推导光谱指数。保留天地图署名，仅按当前视窗浏览，不建设全域瓦片镜像。
>
> 调用方式：本机或部署服务器代理调用，客户端通过同源接口访问，应用Key由服务端保管。

申请允许服务端调用的应用Key；如有IP限制，应授权**实际部署服务的公网出口IP**。浏览器访问的127.0.0.1不是第三方看到的出口IP。按实际账户许可开通地图/地名/逆地理/行政区划对应服务，不承诺一个Key必然获准所有服务，也不预填组织身份、生产域名或固定配额。

## 在平台配置

1. 打开工作台，进入“数据”的天地图服务卡；地图图层中的待配置天地图卡也可进入。
2. 在密码输入框填写账户自有Key，点击“保存并验证”。不要在聊天、截图、代码仓库或公开URL中发送密钥。
3. 查看各项真实检查结果：地图瓦片（影像、注记、标准地图及其注记分项）、地名搜索、坐标地址与行政区划。
4. 部分服务失败时，保留其错误状态；核对账户授权、IP限制、配额和网络后重新验证。保存配置本身不等于调用成功。
5. 可在同一入口清除本机配置。若由环境变量管理，界面不会覆盖，需在本机进程环境修改后重启。

Key仅保存在数据库同级的`integrations/tianditu.json`，文件权限0600，独立于通用业务记录；不出现在HTTP状态响应、地图瓦片模板、下载文件或源码包中。也支持服务进程的`TIANDITU_TOKEN`环境变量，优先于本机文件。重启后连接检查恢复为待验证，避免将上次在线可用当成当前保证。

## 实际使用入口

- **图层面板**：天地图影像与中文注记、天地图标准地图与中文注记；底图与注记分别加载。
- **地图搜索**：输入联想查本机地点、数据与成果；按Enter或点击搜索才提交在线地名检索。网络错误时仍保留本地结果和错误提示。地点不是分析边界。
- **地图地址查询**：显式按当前地图中心查询地址，保留查询坐标和官方来源；不在每次移动时隐式扣配额。
- **天地图服务卡的行政区范围**：输入名称或区划码，选择候选，查看真实返回的参考多边形及下载GeoJSON。无有效几何不生成替代面，也不自动改写分析AOI。
- **数据目录**：分别登记地图、地名地址、行政区参考范围；这些服务不列为已接入的遥感光谱像元或农业分类算法。

## 定量分析的分工

天地图WMTS可改善地图显示、中文地理背景和定位体验，但不提供本项目NDVI/MNDWI/NDMI所需的近红外/短波红外、定标、SCL和明确观测时刻。原生Sentinel-2计算链保留。天地图公开行政轮廓亦不等于确权地块、高标准农田工程边界、农业主体完整名录或当期耕地分布。

行政参考界可为后续省市县选区提供基础，仍需独立完成边界版本管理、影像筛选、多景合成、分类与精度评价，才能形成相应年度/区域定量成果。本版不会因取得边界就宣布省域分类已完成。
